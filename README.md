# Cafeteria DZ

Application de gestion de cafétéria conçue pour le marché algérien,
centrée sur la prévention des vols de caisse en l'absence du gérant.

## Fonctionnalités prévues (V1)

- Connexion des employés par code PIN, avec rôles Gérant et Serveur
- Encaissement en dinars avec calcul du rendu de monnaie
- Ouverture et clôture de caisse à l'aveugle, écarts par employé
- Actions sensibles réservées au gérant, avec motif obligatoire
- Journal d'activité infalsifiable (chaîne de hachage)
- Fonctionnement sans connexion internet

## Technologies

- Backend : Python, Django, Django REST Framework
- Frontend : React
- Base de données : SQLite (développement), PostgreSQL (production)
